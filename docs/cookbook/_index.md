# Cookbook

Recipes for the things an application actually does, end to end. Each one is a
complete example you can paste and then cut down.

- [A webshop checkout](webshop-checkout.md) — a basket with several lines and
  shipping, priced for one tenant, with the fields worth storing on the order.
- [A marketplace sale](marketplace-sale.md) — asserting that a platform facilitated
  the sale, and reading what the law does with that.
- [Backfilling old invoices](backfilling-invoices.md) — pricing last year without
  applying this year's world to it.

For the concepts behind them, see [core concepts](../core-concepts/_index.md).
